## What's new

- **Find and replace** in the Markdown and Visual editors: **Ctrl+F** to find, **Ctrl+H** to replace. All matches are highlighted, with match case, whole word and regular expressions (`$1` works in the replacement). *Replace all* is a single undo step.
- **Paste or drop images:** Ctrl+V a screenshot, or drop an image file into the editor. It's saved in an `images` folder next to your document and linked automatically.
  - *Save As* into another folder copies the document's images along.
  - Images that can't be found are now clearly marked in the preview instead of leaving a blank gap.
- **Full screen (F11):** only the document, without tabs, toolbars or status bar. Press F11 or Esc to exit, or move the mouse to the top edge for an exit button.
- **GitHub alerts:** `> [!NOTE]`, `[!TIP]`, `[!IMPORTANT]`, `[!WARNING]` and `[!CAUTION]` show as coloured boxes, like on GitHub.
- **YAML front matter** (the `---` block at the top of Obsidian, Jekyll or Hugo files) is shown as a tidy properties table instead of a large heading. The outline and word count ignore it.

## Fixes

- Clicking a web link no longer replaces the document with a "This content is blocked" page. Links open in your browser and the document stays put.
- Editing math in Visual mode no longer damages it: formulas (`$…$`, `$$…$$`) show as code there and are saved exactly as written.
- Keyboard shortcuts (Ctrl+S, Ctrl+1/2/3, Ctrl+F…) keep working after using a menu or popup in the tab bar.

## Download

- `MarkdownViewer-1.5.0-setup.msi` (recommended): installer, per user, no admin rights needed. Already installed? The app offers this update automatically.
- `MarkdownViewer-1.5.0.exe`: portable, needs the [.NET 9 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/9.0) (x64).

Each file has a `.sha256` checksum.

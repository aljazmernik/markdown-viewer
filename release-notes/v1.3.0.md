## What's changed

- **The installer no longer needs .NET installed.** It now includes everything it needs, so it works on any Windows 10/11 PC. The portable exe stays small and still uses the .NET 9 Desktop Runtime.
- **Safer updates:** the app verifies each downloaded update against the release's SHA-256 checksum before installing it, and won't install one that doesn't match.
- Fixed a second scrollbar appearing next to documents that contain math formulas.
- Added the MIT license and third-party notices; they are also installed with the app.

## Download

- `MarkdownViewer-1.3.0-setup.msi` (recommended): installer, per user, no admin rights needed. Already installed? The app offers this update automatically.
- `MarkdownViewer-1.3.0.exe`: portable, needs the [.NET 9 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/9.0) (x64).

Each file has a `.sha256` checksum.

> Windows may show "Windows protected your PC" because the app isn't code-signed yet. Click **More info → Run anyway**.

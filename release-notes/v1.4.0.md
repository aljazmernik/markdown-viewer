## What's new

- **Appearance panel** (palette button, top right): pick a theme, font, text size, reading width and a background image.
  - New themes: **Sepia, Solarized Light, Nord, Solarized Dark**, next to System, Light and Dark. The editor, code and diagrams follow the theme.
  - **Your own themes:** "New theme from current" creates a small CSS file you can edit; the app updates as soon as you save it.
  - **Background image** with fill/fit/tile, visibility, blur, and an optional "paper" card behind the text.
- **Export as PDF or HTML** (folder button → Export as…). HTML export is a single file with images, diagrams and math embedded. Exports always use a light, print-friendly style.
- **Print** with Ctrl+P.
- **Uninstalling now removes the `.md` file association** if it pointed at the installed app, so `.md` files go back to opening in your previous app.

## Under the hood

- Automated tests (C# and JavaScript) run on GitHub before every release.

## Download

- `MarkdownViewer-1.4.0-setup.msi` (recommended): installer, per user, no admin rights needed. Already installed? The app offers this update automatically.
- `MarkdownViewer-1.4.0.exe`: portable, needs the [.NET 9 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/9.0) (x64).

Each file has a `.sha256` checksum.

> Windows may show "Windows protected your PC" because the app isn't code-signed. Click **More info → Run anyway**.

## What's new

- **Zoom indicator, like in a browser:** while you're zoomed in or out, the tab bar shows the level (for example *110%*). Click it for **−**, **+** and **Reset** buttons. The controls also appear for a moment when you zoom with Ctrl +/− or Ctrl+mouse wheel.
- **Ctrl+0 resets zoom** to 100%. It's also in the folder menu as *Reset zoom*.
- **Copy file name:** right-click a tab → *Copy file name* copies just the name (like `notes.md`), next to *Copy path*.

## Download

- `MarkdownViewer-1.4.1-setup.msi` (recommended): installer, per user, no admin rights needed. Already installed? The app offers this update automatically.
- `MarkdownViewer-1.4.1.exe`: portable, needs the [.NET 9 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/9.0) (x64).

Each file has a `.sha256` checksum.

> Windows may show "Windows protected your PC" because the app isn't code-signed. Click **More info → Run anyway**.
